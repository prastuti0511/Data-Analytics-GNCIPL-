# GNCIPL Six-Week Data Analytics Internship — Streamlit

This Streamlit application contains the Excel datasets and Power BI files for Weeks 1–6.

## Projects
1. Nutrition Analysis of McDonald's Menu
2. Software Bug Tracker Analysis
3. Climate Change – Glacier Ice-Melt Analysis
4. Water Consumption Dashboard
5. AI-Enhanced Robotics Data Analytics
6. Employment Data Analysis and Skill Gap Identification

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud
1. Create a GitHub repository.
2. Upload `app.py`, `requirements.txt`, and the `data` folder.
3. Open Streamlit Community Cloud and connect the GitHub repository.
4. Select `app.py` as the main file.
5. Deploy.
